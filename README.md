# Maze-Beasts
A first-person shooter random maze game using the pygame library. Made with [Grok 4](https://grok.com).<br/><br/>
Controls:<br/>
WASD to move.<br/>
Left click to shoot.<br/>
Hold Tab to view entire maze.<br/>
F8 to generate a new random maze.<br/>
ESC to exit game.<br/>
